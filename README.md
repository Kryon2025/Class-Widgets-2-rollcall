# 随机点名

独立悬浮窗式随机点名程序（**非桌面组件**），此插件由Deepseek V4 Flash开发。

## 功能

- 独立点名悬浮窗：无边框、置顶、可拖动，点击窗口或"点名"按钮随机滚动点名
- 单独开关：设置页中可随时显示 / 隐藏悬浮窗
- 大小可自定义：设置页中调整窗口宽度与高度（像素）
- 名单导入：支持 txt 与 Word（.docx）文件，每行一个名字
- 自动去序号：`1.小明`、`2．小红`、`(3)小王`、`01 张三` 等格式导入后自动去除序号
- 名单持久化：导入后保存到插件目录 `.roll_roster.json`，重启不丢失

## 使用方法

1. 在 Class Widgets 2 中导入本插件（`com.rollcall`）
2. 打开"设置 → 插件 → 随机点名"
3. 导入名单（选择 txt / Word 文件），可在预览区确认去序号结果
4. 确认"显示点名窗口"开关已开启，桌面即出现点名悬浮窗
5. 点击悬浮窗或"点名"按钮：名字滚动 3 秒后定格随机结果

## 名单格式示例

```
小明
小红
1.张三
2.李四
3.王五
4.赵六
```

导入后名单为：小明 / 小红 / 张三 / 李四 / 王五 / 赵六
