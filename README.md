# 随机点名

独立悬浮窗式随机点名程序（**非桌面组件**），此插件由 Deepseek V4 Flash 开发。

## 功能

### 悬浮按钮
- 无边框、置顶、可拖动；位置自动保存，重启后回到原处
- 拖动范围限制在所有屏幕的联合区域内，不会被拖出屏幕后找不回来
- 菜单打开时拖动按钮不会再导致按钮消失（拖动时自动收起菜单并在屏幕内钳制）
- 大小可自定义（宽 40–160 px，高 30–100 px），实时生效
- **浮窗模式**：圆角半透明 + 悬浮质感，可切换为实心方角样式
- **点击后隐藏**：点名完成后自动收起按钮，适合把按钮当一次性快捷入口
- 左键点击 → 弹出人数菜单（1 / 3 / 5 名）
- 右键点击 → 快捷设置面板（浮窗模式、点击后隐藏、灵动通知、收起按钮）

### 点名表现
- **结果窗口**：名字随机滚动后纵列定格，可拖动移动、拖右下角手柄缩放
  - 滚动过程中可点「提前结束」立即定格
  - 定格后可点「再来一次」重抽或「关闭」收起
- **灵动通知**：从屏幕顶部滑入的胶囊样式，播报后在设定时长后自动收起

### 抽取规则
- **一轮之内不重复**：洗牌队列，同一个人在一轮内不会被抽到两次，抽完自动重洗
- **概率抽点**：为每位同学设置权重（1–1000），权重越大越容易被抽到；此时不重复规则不生效

### 名单
- 支持 txt 与 Word（.docx）导入，每行一个名字
- 自动去序号：`1.小明`、`2．小红`、`(3)小王`、`01 张三` 等格式导入后自动去除
- 设置页可直接增删单个名字，并在列表中查看
- 名单持久化到插件目录 `.roll_roster.json`，权重持久化到 `.roll_weights.json`

## 使用方法

1. 在 Class Widgets 2 中导入本插件（`com.rollcall`）
2. 打开「设置 → 随机点名」
3. 导入名单（选择 txt / Word 文件），或在「手动添加」里逐个输入
4. 按需调整：按钮大小、随机动画时长、点名方式（结果窗口 / 灵动通知）
5. 桌面出现「点名」按钮后，左键点击选择人数即可开始点名
6. 右键按钮可快速切换浮窗模式、点击后隐藏等常用选项

## 名单格式示例

```
小明
小红
1.张三
2.李四
3.王五
4.赵六
```

导入后名单为：小明 / 小红 / 张三 / 李四 / 王五 / 赵六
